# Python Fundamentals Capstone Project | Pandas & NumPy

## Project Overview

This project is a Python Fundamentals Capstone Project completed as part of the Skillovilla Data Analytics training program.

The project focuses on practical data manipulation and analysis using Python, Pandas, and NumPy. It involves creating DataFrames, handling missing values, transforming data, joining datasets, applying conditional logic, and calculating employee-level project costs.

## Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Tasks

The project covers the following 10 tasks:

1. **Create DataFrames:** Create Employee, Seniority, and Project DataFrames and save them as CSV files.
2. **Handle Missing Values:** Replace missing values in the Project Cost column using a running average with a `for` loop.
3. **Split Employee Names:** Separate the Name column into First Name and Last Name and remove the original column.
4. **Merge DataFrames:** Join the Employee, Project, and Seniority DataFrames into one DataFrame named `Final`.
5. **Calculate Bonuses:** Add a 5% bonus based on project cost for employees who completed their projects.
6. **Update Designation Levels:** Demote designation levels for failed projects and remove employee records with designation levels above 4.
7. **Format Employee Names:** Add "Mr." and "Mrs." prefixes to first names and remove the Gender column.
8. **Apply Promotion Logic:** Increase designation levels by 1 for employees older than 29 years.
9. **Calculate Total Project Costs:** Calculate the total project cost for each employee and create a `TotalProjCost` DataFrame.
10. **Filter Employee Records:** Display employee details for employees whose city name contains the letter "o".
